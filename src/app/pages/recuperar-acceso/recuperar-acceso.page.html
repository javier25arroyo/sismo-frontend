Recuperar contraseña

Por seguridad institucional, el restablecimiento de contraseñas requiere la intervención de un administrador del sistema.

Proceso de recuperación

1

Contacta a tu administrador

Comunícate con el administrador del sistema e indica tu nombre de usuario para que pueda identificarte.

2

El administrador genera una contraseña temporal

Desde el panel de administración, el administrador restablecerá tu contraseña y te proporcionará una clave temporal de forma segura.

3

Inicia sesión con la clave temporal

Usa esa contraseña para iniciar sesión. El sistema te pedirá definir una nueva contraseña de forma inmediata.

Nota: La contraseña temporal tiene una vigencia de 24 horas. Si vence, solicita un nuevo restablecimiento.
